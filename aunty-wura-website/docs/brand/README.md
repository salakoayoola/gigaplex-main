# Aunty Wúrà Brand Guidelines

Brand identity system for Aunty Wúrà, a Yoruba language education brand.

## Quick Reference

| Element | Value |
|---------|-------|
| Primary Color | Terracotta `#A0522D` |
| Secondary Color | Deep Forest `#2D4A3E` |
| Accent Color | Wura Gold `#D4A84B` |
| Display Font | Ojuju (Google Fonts) |
| Heading Font | Charis SIL (self-host) |
| Body Font | Andika (self-host) |
| UI Font | Inter (Google Fonts) |

### Yoruba Diacritic Test

All fonts must correctly render: `Ẹ̀kọ́ Yorùbá: Ọjọ́ kan, àwọn ọmọdé ń kọ́ ẹ̀dè Yorùbá.`

## The Brand in One Paragraph

Aunty Wúrà teaches Yoruba language through the lens of the natural world. She's the young aunt who makes learning feel like a conversation - knowledgeable without being academic, culturally grounded without being prescriptive. The brand pairs scientific accuracy with warmth, using rich earth tones and quality illustration to signal that heritage language learning deserves the same production value as any other subject.
