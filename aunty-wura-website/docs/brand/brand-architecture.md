# Brand Architecture

## Overview

Aunty Wúrà is the first expression of a larger ed-tech initiative: teaching African languages through engaging, well-crafted content. The architecture is designed to scale to additional languages, each with its own teacher persona.

## Structure

```
BROWN MELON PRODUCTION ORIGINALS (Parent)
│
├── Aunty Wúrà (Yoruba)
│   ├── Books
│   ├── YouTube
│   └── Website/Digital
│
├── [Future] Uncle Chike (Igbo)
│   └── Same structure
│
├── [Future] [TBD] (Itsekiri)
│   └── Same structure
│
└── [Future] Additional languages
```

## Brand Relationship Model

**Endorsed Brand Architecture**

Each language teacher is a distinct persona with its own personality and regional flavor. They share:

- Educational philosophy and mission
- Quality standards and production approach
- Core visual system (with regional adaptation)
- "A Brown Melon Production Original" endorsement

They differ in:

- Teacher persona and personality
- Regional accent color
- Cultural references and examples
- Language-specific pedagogy

## Shared Elements

### Visual Foundation

| Element | Shared | Adapted |
|---------|--------|---------|
| Color palette structure | Primary/Accent/Neutral system | Specific accent colors per region |
| Typography | Heading + Body fonts | Accent font may vary |
| Illustration approach | Scientific style for books | Regional flora/fauna |
| Quality level | Consistent high craft | - |

### Brand Voice

| Element | Shared | Adapted |
|---------|--------|---------|
| Warmth | Always encouraging | - |
| Accuracy | Scientifically/linguistically correct | - |
| Cultural grounding | Specific and authentic | Regional focus |
| Teacher persona | "Favorite relative" energy | Different relative |

## Regional Accent Colors

Each language persona adds a signature accent color reflecting regional identity:

| Persona | Language | Accent Color | Inspiration |
|---------|----------|--------------|-------------|
| Aunty Wúrà | Yoruba | Wura Gold `#D4A84B` | Gold = Wura |
| Uncle Chike | Igbo | Uli Indigo `#3D5A80` | Traditional Uli patterns |
| [TBD] | Itsekiri | Mangrove Teal `#2D6A6A` | Niger Delta waters |

The core palette (Terracotta, Deep Forest, Warm Cream) remains consistent. The accent color identifies the specific language/persona.

## Naming Convention

Teacher personas should:

- Use culturally appropriate names for the region
- Include a relational title (Aunty, Uncle, etc.)
- Be easy to pronounce across audiences
- Have a meaning that can inform brand expression

## Creating New Language Personas

When expanding to a new language:

1. **Research** - Understand the language's cultural context, regional identity, and learning challenges
2. **Persona development** - Define the teacher's personality, age, style, and teaching approach
3. **Visual adaptation** - Select regional accent color, identify representative flora/fauna
4. **Content strategy** - Determine initial content offerings and platform priorities
5. **Art direction** - Create illustration prompts following established scientific illustration system

## What Stays Constant

- Educational mission
- Quality standards (illustration, production, accuracy)
- Brand architecture and relationship model
- Core visual system structure
- Warm, encouraging voice
- Scientific illustration approach for books
- "Brown Melon Production Originals" endorsement

## What Flexes

- Teacher persona personality
- Regional accent color
- Cultural references and examples
- Flora and fauna in illustrations
- Language-specific teaching approaches
- Accent typography choices
